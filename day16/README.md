 Day 16 — Environment Variables

Today I learned how Linux uses environment variables to store information that programs and the shell can use.

I practised viewing variables, checking the HOME directory, creating temporary variables, removing variables, and understanding the PATH.

I also learned that environment variables can affect how commands and programs work in the current shell.

what surprised me is environment variables provide important configuration information to the Linux shell and applications, while PATH tells Linux where to look for executable commands.
