Command and  What it does 
1.cat : Short for "concatenate." It just prints the entire file straight to your screen, top to bottom, all at once.
2. less: it is used to opens the file in a viewer where you can scroll through one page at a time, instead of dumping everything at once.
3. head: it shows just the first 10 lines of a file. Useful for quickly peeking at the top of a big file without opening the whole thing.
4. head -n : it has the same function as the head command , but you choose how many lines. 
5. tail : it shows the last 10 lines of a file. Great for checking the newest entries in a log file.
6. tail -f: it is used to follow files as soon as new lines get added, they appear live on your screen. Note : -f means follow, tail -f is commonly used to watch a log file update in real time.
7. wc : it means Word count and it gives information about three numbers which are  how many lines, words, and characters (bytes) are in the file.
8. wc -l : it has the same function as wc, but only shows the line count — useful when you just want to know how many lines does this file have?
9. file: it looks inside the file and tells you what kind of file it actually is either text, image, script, compressed archive, without an extension.
10. stat: it shows detailed info about the file not necessarily its contents, but things like: size, permissions, who owns it, when it was created, last modified, last accessed.
