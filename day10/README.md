Day 10 — Security Checkpoint & Audit

Day 10 focused on Linux security auditing and checking user activity on the system.

I learned how to check SUID files, view recent and failed login attempts, see currently logged-in users, check user groups, manage passwords, and view password expiry information.

I also learned how to search my command history for commands that used sudo.

what surprised me was  how to review a Linux system and identify user activity that could be important for security.
