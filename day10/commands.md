 Command and What it does

find / -perm /4000: Searches the system for files with the SUID permission.

last: Shows recent user login sessions.

lastlog: Shows the most recent login for each user account.

w: Shows who is currently logged in and what they are doing.

who: Shows who is currently logged into the system.

group: Shows the groups that your user belongs to.

passwd: Used to change a user's password.

chage -l: Shows password expiry and account aging information for a user.

lastb: Shows failed login attempts. It may require administrator privileges.
 
history \| grep sudo: Searches your command history and displays commands that used sudo.
