Day 11 — Creating & Managing Users

Today I learned how Linux manages users. I practiced creating a new user, giving the user a home directory and Bash shell, setting a password, adding the user to a secondary group, changing the username and shell, and deleting the user when finished.

I also learned that useradd creates users, passwd manages passwords, usermod changes user settings, and userdel removes users.

The practical exercise helped me understand how administrators create and manage user accounts on a Linux system.

what surprised me is how user management commands helps control who can access a Linux system and how their accounts are configured.
