 Commands and what they do

useradd: Creates a new user

useradd -m: Creates a user and their home directory

useradd -m -s /bin/bash: Creates a user with a home directory and Bash shell

adduser: Creates a user through an interactive setup

passwd: Creates or changes a user's password

usermod -aG: Adds a user to another group 

usermod -s: Changes a user's default shell

usermod -l: Changes a user's username 

userdel: Deletes a user 

userdel -r: Deletes a user and their home directory
