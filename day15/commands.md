 Commands and waht they do

id <user>: Shows a user's ID and groups

getent passwd <user>: Shows information about a user account   

usermod -m -G: Moves a user's home directory and changes group membership

passwd <user>: Changes a user's password

apt list --installed: Lists installed packages

apt list --upgradable: Shows packages that can be upgraded

apt update && apt install -y: Updates package information and installs a package

dpkg -l \| grep: Searches installed packages

apt autoremove:Removes unnecessary packages 

history: Shows commands previously entered
