Day 22 — Controlling Processes with Signals

Today I learned how to control running processes in Linux using signals. I practised stopping, terminating, suspending, and resuming processes using commands such as kill, killall, and pkill.

I also learned how to move processes between the foreground and background using fg and bg, and how Ctrl+Z can suspend a running process. I explored nohup and disown for keeping background processes running independently of the terminal.

what surprised me was understanding process signals helps me safely control running programs and manage background tasks on a Linux system.
