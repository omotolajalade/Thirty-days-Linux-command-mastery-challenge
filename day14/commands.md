Command and what the do

dnf update: Updates packages on Fedora/RHEL-based systems

dnf install: Installs a package

dnf remove: Removes a package

dnf search: Searches for a package

yum install: Installs a package using YUM

rpm -qa: Lists installed RPM packages

snap install: Installs an application using Snap

add-apt-repository: Adds a new software repository 

dpkg -i: Installs a .deb package manually

pip / npm install: Installs Python or Node.js packages
