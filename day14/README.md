Day 14 — DNF/YUM & Alternative Installs

Today I learned about different Linux package management tools used to install, update, search, and remove software. I practised commands such as dnf, yum, rpm, snap, dpkg, pip, and npm.

I also learned that different Linux distributions use different package managers. Ubuntu mainly uses APT, while Fedora and RHEL-based systems commonly use DNF/YUM.

what surprised me was how Linux manages software packages and how package installation differs between distributions.
