 Day 13 — APT Package Management

Today I learned how to manage software packages on Debian-based Linux systems using APT. I practiced updating the package list, upgrading installed software, installing new packages, searching for packages, viewing package information, and removing packages.

I also learned that apt update refreshes the list of available packages, while apt upgrade updates installed packages. Commands such as apt install, apt remove, apt purge, and apt autoremove help manage software on the system.

The practical exercise helped me understand how Linux administrators install, update, and remove software from the command line.

what surprised me is that  APT makes it easier to safely manage software and keep a Debian-based Linux system updated.
