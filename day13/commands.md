 Commands and what they do                                     

apt update: Updates the list of available packages

apt upgrade: Updates installed packages

apt full-upgrade: Performs a more complete upgrade

apt install: Installs a package

apt remove: Removes a package but may keep configuration files

apt purge: Removes a package and its configuration files 

apt autoremove: Removes packages no longer needed

apt search: Searches for a package

apt show: Shows information about a package
