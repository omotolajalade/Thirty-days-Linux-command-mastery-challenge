Day 8 — Privilege Escalation & Identity

Day 8 focused on understanding Linux privileges, user identities, and administrative access.

I practiced commands such as sudo, sudo -i, sudo -l, sudo !!, whoami, id, su, and su -.

I learned how to check my current user, view my permissions, run commands with administrator privileges, switch to the root user, and return to my normal account.

what surprised me was how Linux controls administrative access and why using root privileges should be done carefully.
