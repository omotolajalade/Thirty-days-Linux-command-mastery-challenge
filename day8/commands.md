 Commands and what it does
sudo: Runs a command with administrator privileges.  

sudo -i: Opens a root administrator shell. 

sudo -u username command :Runs a command as another user.

sudo !!: Runs your previous command again with administrator privileges.

sudo -l: Shows the commands your account is allowed to run with sudo. 

visudo: Safely opens the sudo configuration file for editing. 

su: Switches to another user.

su -: Switches to another user and loads that user's full environment.

whoami: Shows the username you are currently using.

id: Shows your user ID, group ID, and groups.
