CREATING,COPYING,MOVING,AND DELETING
 Day 2, I learned how to manage files and directories from the Linux command line. I practiced creating directories with "mkdir" and nested directories with "mkdir -p". I also used "touch" to create files.

I learned how to copy files using "cp" and how to copy directories and everything inside them using "cp -r". I learned that the "-r" option means recursive, which allows Linux to work through a directory and its contents.

I also learned how to move and rename files using the "mv" command. For example, moving a file to another directory and changing a filename can both be done using "mv". I practiced deleting files with "rm" and removing directories and their contents using "rm -r". I also learned about "rmdir", which can remove an empty directory.
