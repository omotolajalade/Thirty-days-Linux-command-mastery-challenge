 Commands Covered
mkdir: it creates a new single  directory 
mkdir -p: it Creates nested directories or more than one directory in one go 
Note : -p means creates parent folders too if they don't exist
touch: it means make  a new, empty file 
cp: it means to copy a file 
cp -r: it copies a directory and everything inside it .
Note : -r means recursively 
mv: it means to moves a fileor folder, or renames it if the destination is in the same place 
rm: it is used to delete a file 
rm -r : it Deletes a directory and its contents.
rm -rf : it is used to force-deletes a directory and contents.
rmdirDeletes an emptydirectory only 
Note: it fails if it has anything inside
