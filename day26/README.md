Day 26 — Networking Basics

Today I learned the basics of networking in Linux. I practised checking my IP address and routing information using ip a and ip route, testing connectivity with ping, and interacting with websites using curl and wget.

I also learned how to view network connections and listening ports using netstat and ss, and how to check my system's hostname with hostname and hostnamectl.

What surprised is understanding Linux networking commands helps me see how a system connects to other devices, communicates across networks, and uses network services.
