Day 27 — Remote Access & File Transfer

Today I learned how to remotely access Linux systems and securely transfer files using SSH. I practised generating SSH keys, copying my public key to a remote machine, and connecting without repeatedly entering a password.

I also learned how scp, sftp, and rsync can be used to transfer or synchronize files between systems, and explored the SSH configuration file and basic SSH security hardening.

What surprised is how SSH is an essential Linux skill for securely managing remote servers and transferring files, especially in cloud computing, DevOps, and system administration.
