pwd (print working directory): It shows the current directory/folder I am in at that moment
ls(list): It gives a list of the files in the directory.
ls -l(list and details): It gives a list of the files with additional information
ls -a(list and hidden files): It shows the list of all the files that are hidden.
ls -la (list, hidden files, and details): It shows the list of the hidden files and details about each file
ls-lh(list ,details and human readable): It shows details of all the files and ensures everything is in plaintext 
cd(change directory):it is used to move from folder/directory to another one.
cd .. : it is used to move to the directory above the current one you are working with
cd ~ : it takes you straight to the home directory no matter the directory you are
cd - : it takes you to the previous directory
