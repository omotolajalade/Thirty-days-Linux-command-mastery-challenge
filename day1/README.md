BASIC OPERATION
 Day 1, I learned the basic concepts of the Linux terminal and how to navigate through the Linux filesystem. I learned how to use "pwd" to display my current working directory and "ls" to view the contents of a directory. I also learned different options of the "ls" command, including "ls -l" for detailed information, "ls -a" for showing hidden files, "ls -la" for showing both detailed and hidden files, and "ls -lh" for displaying file sizes in a human-readable format.

I also learned how to move between directories using the "cd" command. I practiced "cd .." to move to the parent directory, "cd ~" to return to my home directory, and "cd -" to return to the previous directory.
