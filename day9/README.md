Day 9 — Integrity, Encryption & Firewalls

Day 9 focused on Linux file integrity, encryption, and firewall security.

I learned how to use md5sum and sha256sum to check whether files have been changed. I also learned how GPG is used to encrypt and decrypt files.

I practiced chattr +i to make a file immutable and lsattr to view file attributes.

I also learned about UFW, which means Uncomplicated Firewall, and practiced using ufw enable, ufw allow, and ufw status to manage firewall access.

what surprised me was how Linux can protect files, secure information, and control network connections.
