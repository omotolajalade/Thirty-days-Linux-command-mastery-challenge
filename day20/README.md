Day 20: Text Processing & Pipes

Today I learned how to process and manipulate text directly from the Linux terminal. I practised using grep to search for specific text, sort to arrange results, and uniq to remove duplicate entries.

I also learned how cut and awk can extract specific columns or fields from text, while sed can be used to modify text. Most importantly, I practised using the pipe | to connect commands together, allowing the output of one command to become the input of another.

The practical exercise helped me understand how Linux can process large amounts of text and log data efficiently without needing a graphical application.

what surprised me is how linux commands become much more powerful when combined with pipes to create a complete text-processing workflow.
