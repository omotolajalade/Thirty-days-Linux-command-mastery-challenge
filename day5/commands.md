tree — show directory structure as a tree
tree -L  — limit tree depth to different levels
ln — create a hard link
ln -s  — create a symbolic (soft) link
readlink  — show what a symlink points to
realpath — resolve the absolute, canonical path
basename — strip directory and (optionally) suffix, leaving just the filename
dirname  — strip the filename, leaving just the directory
pushd / popd — push/pop a directory onto a stack while navigating, so you can jump back
ls -lt — list files sorted by modification time, newest first
