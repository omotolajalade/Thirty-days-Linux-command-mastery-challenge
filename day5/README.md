Day 5 — Paths, Links & Tree Structures

Today I learned how to view Linux directory structures, work with file paths, and create links. I practiced commands such as tree, ln, ln -s, readlink, realpath, basename, dirname, pushd, popd, and ls -lt.

I also learned the difference between a hard link, which is another name for the same file, and a symbolic link, which acts as a shortcut pointing to another file.
