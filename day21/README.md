 Day 21 — Viewing Processes

Today I learned how to view and monitor running processes in Linux. I practised using ps, top, and htop to see processes and system activity, and pgrep to find the PID of a process.

I also learned how pstree displays processes in a parent-child structure, lsof -i helps identify processes using network connections, and jobs shows background jobs running in the current terminal.

what surprised me was how understanding processes helps me see what is running on a Linux system, how processes are connected, and which processes may be using system or network resources.
