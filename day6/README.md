Reading & Setting Permissions

Today I learned about Linux file permissions and how to control who can read, write, and execute a file.

I practiced using ls -l to view permissions and chmod to change them. I also learned three ways to set permissions: relative, assignment, and octal.

For the practical drill, I created a script and changed its permissions to rwxr-xr-x using the three methods, checking the result after each change.

what suprised me was how Linux controls access to files.
