 Day 19 — Vim Navigation & Search/Replace

Today I learned how to navigate through Vim more efficiently and search for specific text within a file. I practised jumping to the beginning, end, and specific lines, searching forward and backward, moving between search results, deleting words and characters, and opening new lines.

I also learned how to use Vim’s search-and-replace command to replace text throughout an entire file.

what surprised me is vim becomes much more powerful when I can quickly navigate, search, edit, and replace text without leaving the terminal.
