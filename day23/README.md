 Day 23 — Init Systems & systemd Basics

Today I learned about systemd, the system and service manager used by modern Linux systems. I practised starting, stopping, restarting, and reloading services using systemctl.

I also learned how to enable or disable services at system startup and how to check whether a service is currently active or configured to start automatically.

What suprised me is systemctl helps administrators control and monitor Linux services, making it an important tool for system administration, cloud computing, and DevOps.
