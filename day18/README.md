 Day 18 — Vim Fundamentals

Today I learned the basics of Vim, a powerful terminal-based text editor.

I practised opening and creating files, entering Insert mode, returning to Command mode, saving, quitting, deleting lines, copying and pasting, and undoing changes

what surprised me was Vim works differently from normal text editors because it uses different modes. Learning when to type, when to use commands, and how to save or exit is essential for working comfortably in the Linux terminal.
