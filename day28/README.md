 Day 28 — Bash Scripting Foundations

Today I learned the foundations of Bash scripting and how to combine Linux commands into reusable scripts. I practised creating and executing a Bash script, working with variables, accepting user input, and using command substitution.

I also learned how to use if, elif, and else statements to make decisions, as well as for and while loops to repeat tasks.

what surprised was how bash scripting allows me to automate repetitive Linux tasks instead of running commands manually, making it an important skill for system administration, DevOps, and cloud computing.
