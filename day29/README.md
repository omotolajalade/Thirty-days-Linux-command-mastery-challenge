 Day 29 — Functions, Arguments & Automation

Today I learned how to make Bash scripts more reusable and automated. I practised creating functions, passing arguments to scripts, checking exit statuses, and using tools such as trap and logger.

I also learned about crontab and how cron scheduling can automatically run scripts at specific times. I explored nohup for running scripts independently of the terminal and learned how Bash arguments such as $0, $1, $#, and $@provide information to a script.

what surprised was  bash becomes much more powerful when scripts can accept input, reuse functions, handle events, record activity, and run automatically on a schedule.
