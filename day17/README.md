 Day 17 — Persisting Configuration

Today I learned how to make **shell settings permanent** instead of having them disappear when the terminal is closed.

I practised working with the .bashrc file, adding environment variables and aliases, and reloading the configuration without restarting the terminal.

I also learned how to use commands such as alias, unalias, type, which, and whereis to inspect and manage commands.

what surprised me was .bashrc allows me to customize my Bash environment and make useful settings and shortcuts available whenever I start a new terminal session.
