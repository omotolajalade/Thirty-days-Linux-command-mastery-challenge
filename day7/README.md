Day 7 — Ownership & Special Bits

Today I learned how Linux manages file ownership and special permissions. I practiced changing file groups with chgrp, using chown, and applying the SGID permission to a shared folder.

I also learned about SUID, SGID, the sticky bit, and ACLs, and practiced finding SUID files .

what surprised me was how Linux controls ownership and access when files are shared between users.
