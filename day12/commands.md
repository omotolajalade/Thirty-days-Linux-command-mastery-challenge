 Command and what do they

groupadd: Creates a new group

groupdel: Deletes a group

gpasswd: Adds a user to a group

gpasswd -d: Removes a user from a group

getent group: Shows information about groups

getent passwd: Shows information about users

groups: Shows which groups a user belongs to

id -Gn: Shows the user's group names

newgrp: Switches to another group

cat /etc/group: Displays the system's group information
