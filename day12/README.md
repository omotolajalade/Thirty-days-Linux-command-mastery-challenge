Day 12 — Groups & Access Control

Today I learned how Linux uses groups to organize users and manage access. I practiced creating and deleting groups, adding and removing users from groups, and checking group membership.

I also learned how groupadd creates a group, gpasswd manages group membership, groups shows the groups a user belongs to, and id -Gn displays the user's group names.

The practical exercise helped me understand how groups make it easier to manage permissions for multiple users.

 what surprised me is how commands like gpasswd and more organize users and control access to resources more efficiently
